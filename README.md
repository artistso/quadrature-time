# The Hilbert-Space Quadrature Conjecture

*Time as the wave-function-generated quadrature of circular phase*
Steven Michael Allen Owens, independent researcher

This repository contains a revised manuscript, a referee-style review of the earlier draft, and a tested Python package. The package reproduces every figure and number in the paper.

## The idea in one paragraph

A quantum state's overall phase lives on a circle (the U(1) fibre of Hilbert space) and cannot be observed. If the universe's wave function entangles a **clock** with a **system**, the relative phases of the clock's energy components become a clock reading. The Born rule is a quadratic, "squaring" map. It turns those circular amplitudes into an ordinary probability distribution over clock readings and conditional system states. The **conjecture** says this is all that time is: no external time parameter, only the quadrature structure generated by the universal wave function. Technically this builds on the Page–Wootters mechanism with covariant clock observables (POVMs); see the paper for prior work.

## What is solid, and what is not

| Status | Content |
|---|---|
| ✔ Established (standard, attributed) | Exact Page–Wootters conditioning with a covariant Holevo phase POVM: uniform clock marginal and exact Schrödinger evolution; positive-frequency selection; proper-time and gravitational time dilation; twin-shell decoherence. |
| ✔ New and correct | Line vs. circle via the **Zak transform**. **Winding marginalization:** a cyclic clock read without its turn counter keeps only coherences with (E_j − E_k)/ħω ∈ ℤ. Separation of **unsharp readout** (static suppression) from **diffusive clock error** (Lindblad form). |
| ⚠ Model-dependent | Any decoherence *rate* needs the clock-diffusion time T_C. The heuristic T_C ~ ħ/ΔE_C is not derived, and with the natural energy identification it is already ruled out by transmon T₂ data. |
| ✎ Heuristic or open | Euclidean/no-boundary reading; inflationary back-reaction; Hubble-rate variance; non-Abelian clocks. |

`notebooks/finite_clock/README.md` is the entry point for the one piece of this project
that is a self-contained research line: how accurately a finite, equally spaced clock
spectrum can represent an arbitrary (incommensurate) spectrum, and for how long. It
records the fidelity bound of v5, the exact assignment optimum of v7, a universal
N-level bound that follows from them, and precisely what the next step is.

## Quick start

```bash
git clone https://github.com/artistso/quadrature-time.git
cd quadrature-time
pip install numpy scipy matplotlib pytest
pytest                          # 24 tests, ~45 s
python scripts/make_figures.py  # regenerate figures
python -m qtime.estimates       # (run with PYTHONPATH=src) print the numbers in Sec. VI
```

Minimal example: exact conditioning, then the effect of unsharp readout.

```python
import numpy as np
from qtime import clocks as qc
psi = qc.pw_constraint_state(N=128, levels=[0, 4], amplitudes=[1, 1])   # |Psi> in C^128 (x) C^2
p, rho = qc.condition_on_clock(psi, qc.sharp_phase_povm(128))            # p = 1/N, exact evolution
p, rho_u = qc.condition_on_clock(psi, qc.smeared_phase_povm(128, 0.15))  # constant suppression
print(abs(rho[0, 0, 1]), abs(rho_u[0, 0, 1]), 0.5 * np.exp(-0.5 * 16 * 0.15**2))
```
