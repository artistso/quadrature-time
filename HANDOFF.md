## 4. Key results to remember (do not reintroduce the old errors)

- **Circle vs line.** Periodizing does *not* remove commensurability (E/ħω ∈ ℤ). The Zak transform writes the line as a direct integral of twisted circles. A cyclic clock read without its winding number multiplies the coherences by D_M(ν), and |D_M| ≤ 1/(M|sin πν|) off the integers.
- **Szegő kernel.** Σ_{n≥0} e^{inx} = πδ + ½ + (i/2) P.V. cot(x/2). The δ is counted once, not twice.
- **Finite clocks.** Unsharp readout gives only a *static* factor e^{−ν²σ²/2}. Lindblad decay Γ = T_C ΔE²/(2ħ²) needs Assumption 1 (σ_t² = σ₀² + T_C t). T_C ~ ħ/ΔE_C is a dimensional heuristic, not derived.
- **Modular operator:** Δ = ρ_C⁻¹ ⊗ ρ_S. The relation t = −ħβs holds only for Gibbs Schmidt spectra.
- **Circuit QED.**
  - Using the qubit gap ω_s gives T₂ ≲ 10 ns, so that identification is *excluded*.
  - Using χ needs a justification and gives 5–170 s⁻¹.
  - **n_crit ≈ Δ/4χ ≈ 250**, so a photon-number sweep to 10⁴ leaves the dispersive regime. Three decades inside it require χ/2π ≲ 2.5 kHz, which gives 10⁻³–10⁻⁵ s⁻¹.
- **Dirac.** A Hardy (one-sided) clock *removes* Zitterbewegung; damping occurs only for a two-sided clock under Assumption 1.
- **Gravity.** H_grav = N^{1/2} √(c²P² + M²c⁴) N^{1/2}. The near-horizon rate scales as ρ_proper⁻¹ ∝ (r − r_s)^{−1/2}. ΔE\* = |ΔE|/(2^{1/4}|ΔN|^{1/2}) and Γ_min = 2^{1/4}|ΔE||ΔN|^{1/2}/ħ; both are heuristic.
- **Hawking temperature:** k_B T = ħκ/(2πc). It is supplied by Bisognano–Wichmann/Sewell; the framework only reinterprets it.
- **Interferometer.** The original simulation was *not* undersampled; that claim was retracted. Its window contains about 12 full revivals, so the Gaussian envelope is valid only before the first one.
- **Not carried over** (open problems only): inflationary back-reaction (k-independent, no tilt), Hubble-rate variance (ansatz), non-Abelian clocks (Γ_YM dimensionally wrong), and Hartle–Hawking as a theorem (it is Conjecture 2).
